# High-Level Design (HLD)

System-level architecture of the task management UI.

## What goes here

- Architecture overview and diagrams
- Main modules and how they interact (UI, state management, API/data layer)
- Tech stack choices and how they fit together
- Data flow and integration points with external services
- Cross-cutting concerns: auth, error handling, logging, performance

## Conventions

- Keep it at module level; component internals belong in `../lld`
- Link to the requirements (`../requirements`) each section satisfies
