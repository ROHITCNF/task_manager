# Architecture Decision Records (ADR)

Records of significant technical decisions and the reasons behind them.

## What goes here

One file per decision, e.g. choice of framework, state library, styling approach, or testing strategy.

## Conventions

- File name: `NNNN-short-title.md`, e.g. `0001-use-react-with-vite.md`
- Each ADR has these sections:
  - **Status**: Proposed / Accepted / Deprecated / Superseded by ADR-NNNN
  - **Context**: the problem and the constraints on it
  - **Decision**: what was chosen
  - **Consequences**: trade-offs and follow-up work
- ADRs are append-only. To change a decision, write a new ADR that supersedes the old one.
