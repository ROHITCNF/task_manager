# Prompts

AI prompts used to build this project, kept for reproducibility and review.

## What goes here

- Prompts given to AI assistants for generating requirements, designs, and code
- Reusable prompt templates (e.g. "generate LLD from HLD section")
- Notes on which prompts worked well and which needed rework

## Conventions

- One file per task or phase, e.g. `01-project-setup.md`
- Record the prompt, the tool/model used, the date, and a link to the resulting artifact or commit
