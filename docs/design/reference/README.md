# Design Reference

Visual reference material the UI is built from.

## What goes here

- Mockups, wireframes, and screenshots (PNG/SVG/PDF)
- Figma links and exported frames
- Inspiration and competitor examples, with notes on what to take from each

## Conventions

- Name files by screen or component, e.g. `task-list-desktop.png`
- Note the source and date for each exported design so stale references are easy to spot
