# Low-Level Design (LLD)

Detailed design for individual modules and components.

## What goes here

- Component breakdown, props, and state
- Data models and TypeScript types/interfaces
- API contracts (endpoints, request/response shapes)
- State management details (stores, actions, selectors)
- Edge cases, validation rules, and error states

## Conventions

- One file per module or feature, e.g. `task-card.md`
- Each LLD should follow from a section of the HLD (`../hld`)
